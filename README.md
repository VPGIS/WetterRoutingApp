# VP Routing

Routing-Anwendung mit Wetterdatenintegration auf Basis von OpenStreetMap/OSMnx.

Das Projekt besteht aus:

- einem FastAPI-Backend
- einem browserbasierten Frontend
- Routing-Logik mit NetCDF-Wetterdaten

## Installation

Die Installationsanleitung befindet sich unter:

[docs/installation.md](docs/installation.md)

## API-Dokumentation

Die Swagger-Dokumentation wird automatisch von FastAPI bereitgestellt, sobald das Backend laeuft:

```text
http://127.0.0.1:8000/docs
```

Die OpenAPI-Spezifikation ist unter folgender Adresse verfuegbar:

```text
http://127.0.0.1:8000/openapi.json
```
